Privacy Policy For The App Mapnik - lockscreen map. 
The app does communicate with vector (https://mapnik.duckdns.org/world_v1) and 
raster (https://mapnik.duckdns.org/natural_earth_shaded) tile servers. 
Tyhe app does communicate with routing/navigation server (https://mapnik.duckdns.org/valhalla/route)
The app temporarily caches map tiles and Q&A data from servers.
The developer reserves the right to change the privacy at any time.
